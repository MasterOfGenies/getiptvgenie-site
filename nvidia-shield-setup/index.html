NVIDIA Shield setup guide

Install IPTV Genie on NVIDIA Shield, the best IPTV box there is

The Shield is the fastest Android TV box you can buy, and IPTV Genie uses all of it: instant channel changes, huge playlists, and four games at once in multi-view.

  1. Install Downloader

    Open the Google Play Store on your Shield, search Downloader, and install Downloader by AFTVnews.

  2. Get IPTV Genie

    Open Downloader, type the IPTV Genie code from our download page, and select Go.

  3. Allow the install

    When Android asks, select Settings and turn on Allow from this source for Downloader, then press Back and choose Install.

    If you're not asked: Settings → Device Preferences → Security & restrictions → Unknown sources → turn on Downloader.

  4. Sign in

    Open IPTV Genie, pick Xtream Codes or M3U playlist, and enter your provider's details. Your 7-day free trial starts right away.

Google TV and Chromecast

Same steps. If Android doesn't ask in step 3: go to Settings → System → About and select Android TV OS build 7 times to turn on developer mode, then Settings → Apps → Security & restrictions → Unknown sources → turn on Downloader.

Get the most out of a Shield

  • Watch four at once. In the player, open the quick menu (☰) and choose Watch 4. Shield runs four live channels side by side, edge to edge.
  • Try AI upscaling. On 2019 Shield models, AI-enhanced upscaling in the Display & Sound settings sharpens 720p and 1080p channels on a 4K TV.
  • Use Ethernet. The Shield's gigabit port is the single best fix for buffering.
  • Map a button. The Shield remote's customizable button can open IPTV Genie straight from anywhere.

Shield questions

Is NVIDIA Shield good for IPTV?

It's the best Android TV box for IPTV. Its processor and memory handle huge playlists and four-at-once multi-view easily, and the Shield TV Pro has the most headroom.

Shield TV or Shield TV Pro for IPTV Genie?

Both are excellent. The Pro has more memory and storage, which helps with four-channel multi-view and very large playlists.

Does IPTV Genie work on Google TV and Chromecast?

Yes. The same steps work on Google TV Streamer, Chromecast with Google TV and TVs with Google TV built in; only the settings menu names differ slightly.
