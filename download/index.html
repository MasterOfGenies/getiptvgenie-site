  1. Install DownloaderOn your Fire TV, search for "Downloader" and install it (free, by AFTVnews).
  2. Allow installs from DownloaderSettings → My Fire TV → Developer options → Install unknown apps → Downloader → On. (No Developer options? Settings → My Fire TV → About, then press OK on your device name 7 times.)
  3. Enter the codeOpen Downloader and type the code — coming soon —, then press Go.
  4. Install and openChoose Install, then Open. IPTV Genie also appears in your apps.
